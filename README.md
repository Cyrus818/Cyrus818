My research focuses on **medical image analysis and medical LLM applications**, including 4D Flow MRI, vessel segmentation, hemodynamic modeling, and multimodal LLM systems (RAG, agents, evaluation, and tool use) for healthcare.

### Research Interests

- **Medical Image Analysis**: 4D Flow MRI, vessel segmentation, velocity-field modeling, hemodynamic analysis.
- **Medical LLM Applications**: multimodal medical QA, RAG, agents, model evaluation, hallucination analysis, tool use.

### Selected Projects

| Project | Description |
| --- | --- |
| **MedBench-ZH (MediVision-LLM)** | First systematic multimodal evaluation benchmark for Chinese medical imaging, with a bilingual data pipeline, 8–10 model systematic evaluation, and clinical workflow assessment. |
| **BiMedSeg** | Bilingual medical reasoning segmentation: combines an LLM with SAM2 to segment the specified structure from Chinese/English clinical instructions, with refusal output when the structure is absent. |
| **TopoBudgetVessel** | Efficient topology-aware vessel segmentation for 3D medical images, shifting compute budget from background redundancy to vessels/centerlines/bifurcations. |
| **PhysioWSS** | Self-supervised 4D Flow MRI velocity-field denoising with spectral neural operators for hemodynamic analysis. |
| **4DFlowUDA** | Unsupervised domain adaptation and uncertainty-aware segmentation for 4D Flow MRI. |
| **MedResearch Agent** | A desktop AI workspace for biomedical research workflows, supporting literature surveys, research exploration, and experiment deployment. |
